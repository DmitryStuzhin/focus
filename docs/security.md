# Безопасность Focus

## Коды доступа (ТЗ №3)

Код входа хранится как HMAC, сравнивается через `timingSafeEqual`, действует 10 минут и удаляется после использования. Новый принятый запрос на отправку отзывает предыдущий код. После пяти ошибок код блокируется. Десять ошибок для одного адреса за 15 минут блокируют проверку независимо от IP и числа запрошенных кодов. Дополнительно действует предел 50 проверок с IP за 15 минут.

Коды подписки — случайные токены, хранящиеся как SHA-256. Дата окончания задаётся в конфигурации. Код закрепляется за одним аккаунтом. Повторное применение для владельца идемпотентно. После пяти неудачных активаций для аккаунта или 20 с IP за 15 минут проверка временно блокируется, включая запросы со старым заголовком клиента.
