# План развития Focus

| Этап | Изменения | Проверка |
| --- | --- | --- |
| Сайты и интерфейс | Четыре сценария на главной, панель результата, версии и восстановление, ZIP, ссылка на выбранную версию, отмена публикации | Создать сайт, изменить его и открыть отправленную ссылку без входа |
| Документы и выгрузки | Открытие CSV и XLSX, сравнение по ключу, экспорт изменений в XLSX, экспорт ответов в DOCX и PPTX | Сверить два прайса с разным порядком строк, открыть экспорт в офисном приложении |
| Проекты и синхронизация | Инструкции проекта, перенос локального проекта, хранение по аккаунту, защита от перезаписи при параллельных правках | Продолжить работу во втором браузере, проверить изоляцию аккаунтов и конфликт версий |
| Исследование | Редактируемый план, несколько запросов, режимы источников, проверяемые ссылки и ограничение затрат | Проверить источники, ошибки провайдера и продолжение после частичного сбоя |
| Долгие задачи | Потоковый вывод текста, этапы обработки, отмена, сохранение состояния задачи и восстановление после закрытия вкладки | Остановить ответ, переподключиться, убедиться, что завершённый результат сохранился |
| Интеграции | Подключаемые источники, GitHub, публикация на собственном домене | Проверить разрешения, отключение и отзыв доступа. Для включения потребуются настройки провайдеров и домена |

## Как проверить эту ветку

- **Сайты.** «Версии и ссылки» открывает историю, сравнение соседних HTML-версий и публикацию выбранной версии. «Выбрать блок» добавляет его в черновик чата. Ссылка на версию открывается без аккаунта. Публикация поддерживает самодостаточный HTML и встроенные стили и скрипты.
- **Выгрузки.** В разделе «Таблицы» выбери CSV или XLSX для каждой стороны и укажи уникальный ключ. Читается первый лист, используются значения ячеек. Лимит составляет 5 000 строк на входной файл и 64 столбца. DOCX, PPTX и XLSX можно прикрепить к диалогу для извлечения текста. Для выгрузки в DOCX и PPTX используй экспорт под ответом.
- **Синхронизация.** Открой настройки аккаунта. Сохрани локальное пространство, затем загрузи копию на другом устройстве. Автосохранение включается отдельно на устройстве. Запись с устаревшей версией блокируется. Лимит серверного снимка вместе с вложениями составляет 8 МБ.
- **Исследование.** Отредактируй основной и дополнительные запросы и выбери источники. После запуска в фоновом режиме можно закрыть вкладку. Результат появится при следующем открытии этого диалога на том же устройстве. Активные задачи помечаются как прерванные при перезапуске процесса Focus.
- **Потоковый чат.** Видимый текст появляется по мере получения событий OpenRouter или Gemini. Предпросмотр сайта появляется после проверки полного HTML. Обычные JSON-клиенты продолжают работать через тот же endpoint.

Подключение сторонних аккаунтов, двусторонняя синхронизация GitHub и собственные домены для публикаций остаются отдельным этапом. Для первой версии используются импорт файлов, ZIP-экспорт и ссылки в домене Focus.
