# Статус продуктового ТЗ Focus

Это статус веток на проверку. Проверки в рабочей среде и исследования участников фиксируются по факту.

| Раздел | Сделано | Остаётся до полной приёмки |
| --- | --- | --- |
| P1–P4 | Черновики позиционирования, названия, слогана и словаря, вычитан вход | Интервью, согласование, проверки занятости и товарных знаков, смена имени и домена, вычитка остальных экранов, публикация метаданных |
| P5 | Существующий знак Focus | Новая айдентика, PWA и OG, скриншоты |
| P6–P8 | Публичные страницы, README, объяснение хранения и провайдеров, модель и предупреждение о лимите | Тарифы и проверка лендинга на пяти участниках, локальная проверка отображения модели во всех режимах |
| O1–O6 | Гостевые инструменты и сценарии, пустые состояния, подсказки, команды, необязательная анкета | Замер времени первого результата и отсева, проверка сценариев в браузерах |
| U1–U6 | Режимы, лимит, мобильная навигация, черновики и отмена удаления, действия с ответом, переключатели контекста | Раздельный остаток по единицам использования и влияние тарифа, отмена перемещения и правок, повтор другой моделью, точный перечень автоматически отобранных фрагментов и полная оценка токенов |
| U7–U14 | Предпросмотр офисных форматов, повтор запроса, палитра, группы настроек, пояснение режимов глубины, оформление, камера, клавиатура в меню | Групповые операции и фильтры файлов, единые состояния для остальных экранов, голос и свайпы, полноценная проверка на телефоне, WCAG AA и экранный диктор |
| F1–F4 | Сопоставление выбранных файлов, проверяемые ссылки на строки текстовых извлечений, шаблоны с DOCX, пользовательский чек-лист | Полная обработка больших проектов и обрезанных материалов, проверка качества ответов, PDF и заполнение полей |
| F5–F9 | Локальный профиль, сводная и диаграмма по группам, предварительный просмотр очистки, точная сверка по составным ключам | Автоматическое пояснение профиля моделью, проверка формул Excel и SQL на данных, финансовые калькуляторы, нечёткое сопоставление, интервью для приоритета правил |
| F10–F12 | Личные шаблоны с переносом JSON, отчёт исследования с запросами, датой и источниками | Каталог ролей, редактор текста с принятием отдельных правок, проверка исследования на данных пользователя |
| F13–F18 | В проекте есть исходные режимы изображений, сайтов и кода | Полное расширение их возможностей по ТЗ, в том числе галерея с тегами и пакеты вариантов, несколько вариантов сайта, изолированный запуск скриптов, свои ассистенты, импорт ChatGPT и Claude, отправка из браузера |
| F19–F20 | Гипотезы из ТЗ | Подтверждение спроса, затем Telegram и публичный API |
| T1–T5 | В предыдущей ветке есть временный технический лимит, в интерфейсе описано его действие | Исследование стоимости и готовности платить, тарифы, пробный период, платежи и чеки, оферта, проверка промокодов |
| R1–R6 | Две страницы с инструментами, три копируемых учебных проекта, текстовый обмен ответом, обратная связь, дорожная карта, журнал и поиск по справке | Страница НДС, расширение галереи, реферальные ссылки и возможность отзыва диалога, видео, сообщество |
| M1–M4 | Сценарии исследования, определения метрик, шаблон обзора | 8–10 интервью, 5 пользовательских тестов, добровольный агрегированный сбор, реальные данные и регулярные обзоры |

Внешние условия приёмки из первого ТЗ остаются открытыми до фактической проверки в кабинетах и на серверах. В частности, это лимиты провайдеров, защита основной ветки и 2FA, сканирование всей истории, развёртывание, внешние резервные копии с восстановлением и юридическое согласование.
