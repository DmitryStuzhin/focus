# Эксплуатация Focus

## Лимиты провайдеров (ТЗ №1)

Включите вход на VPS. Автономный Worker обслуживает статические ресурсы и отклоняет API-запросы без серверной сессии. Открыты служебные маршруты входа и проверки готовности.

Укажите восемь положительных целочисленных лимитов в приватном окружении процесса:

| Переменная | Что ограничивает |
| --- | --- |
| `FOCUS_BUDGET_GLOBAL_DAY_TOKENS` / `FOCUS_BUDGET_GLOBAL_MONTH_TOKENS` | Резерв токенов для всех пользователей за сутки / месяц |
| `FOCUS_BUDGET_USER_DAY_TOKENS` / `FOCUS_BUDGET_USER_MONTH_TOKENS` | Резерв токенов аккаунта за сутки / месяц |
| `FOCUS_BUDGET_GLOBAL_DAY_USD_MICROS` / `FOCUS_BUDGET_GLOBAL_MONTH_USD_MICROS` | Резерв денег для всех пользователей за сутки / месяц |
| `FOCUS_BUDGET_USER_DAY_USD_MICROS` / `FOCUS_BUDGET_USER_MONTH_USD_MICROS` | Резерв денег аккаунта за сутки / месяц |

Один доллар — 1 000 000 USD micros. Окна календарные, по UTC. Укажите тарифы активных путей перед переключением релиза:

| Переменная | Единица |
| --- | --- |
| `FOCUS_BUDGET_GOOGLE_TEXT_USD_MICROS`, `FOCUS_BUDGET_OPENROUTER_TEXT_USD_MICROS` | USD micros за миллион токенов. Используйте максимальную цену среди возможных моделей, типов входа и выхода. |
| `FOCUS_BUDGET_CLOUDFLARE_IMAGE_USD_MICROS`, `FOCUS_BUDGET_OPENAI_IMAGE_USD_MICROS`, `FOCUS_BUDGET_OPENROUTER_IMAGE_USD_MICROS` | USD micros за самый дорогой разрешённый вызов соответствующего генератора, включая правки и входное изображение. |
| `FOCUS_BUDGET_TAVILY_SEARCH_USD_MICROS` | USD micros за один поисковый вызов, включая запас на изменение цены. |

Focus записывает резерв в SQLite до отправки каждого запроса к провайдеру. Повторы, отменённые и неудачные вызовы расходуют резерв. Для текстовых моделей резерв токенов складывается из длины сериализованного тела в байтах и запрошенного максимума выхода. Изображения и поиск расходуют денежный резерв по фиксированной ставке. Резерв — локальная оценка, фактическую стоимость и расход токенов сверяйте с кабинетами провайдеров. При неполной конфигурации внешний вызов блокируется с HTTP 503, при исчерпании — с HTTP 429.

Используйте отдельные ключи и проекты для Focus. Настройте ограничения в кабинетах до запуска:

- **Google Gemini** — установите лимит проекта в AI Studio → Spend → Monthly spend cap. Google указывает на задержку применения и ограничения по типу биллинга. [Документация](https://ai.google.dev/gemini-api/docs/billing#spend-caps)
- **OpenRouter** — задайте конечный лимит отдельного ключа и подходящий период сброса. [Документация](https://openrouter.ai/docs/api/api-reference/api-keys/create-keys)
- **Cloudflare** — Workers Free останавливает генерацию на бесплатной квоте. Для платных моделей проверьте доступность предоплаченных кредитов AI Gateway. Прямой Workers Paid тарифицирует превышение квоты. [Документация](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- **OpenAI** — в настройках Limits отдельного проекта задайте бюджет и включите Enforce a hard limit. Сверьте лимиты организации и допустимые модели проекта. [Документация](https://help.openai.com/en/articles/9186755-managing-projects-in-the-api-platform)
- **Tavily** — оставьте pay-as-you-go выключенным для ограничения включёнными кредитами или согласуйте лимит платного плана. [Документация](https://help.tavily.com/articles/8298987937-billing-credits-usage-limits)

## Адрес клиента (ТЗ №2)

В `TRUST_PROXY` перечислите точные IP непосредственных nginx-прокси, разделённые запятыми. Для локального nginx используйте адрес из `proxy_pass` при совпадении с адресом, с которого nginx устанавливает соединение. Для подключения без прокси оставьте переменную пустой. Перед обновлением замените старое значение `1`. Без доверенного TCP-соседа Focus использует адрес сокета.

В многоуровневой конфигурации внешний прокси перезаписывает `X-Real-IP` адресом клиента. Следующий nginx принимает этот заголовок только с точных адресов внешнего прокси через `set_real_ip_from` и `real_ip_header X-Real-IP`. Перед отправкой в Node этот nginx формирует заголовок из своего `$remote_addr`. Проверьте активную конфигурацию через `nginx -T` и выполните `nginx -t` перед перезагрузкой.

## Администрирование (ТЗ №4)

До обновления добавьте в окружение `FOCUS_ADMIN_ALLOWED_IPS` со списком точных адресов доверенных рабочих станций или VPN через запятую. Пустой список закрывает панель. Адрес проверяется на каждом запросе через правила доверия прокси. После пяти последовательных ошибок с одного адреса вход блокируется на 15 минут. Успешный вход сбрасывает счётчик адреса. Смена хеша пароля отзывает выданные этим паролем административные сессии.

Таблица SQLite `admin_login_audit` хранит результаты входа 90 дней. Адрес записывается в виде хеша, а событие доступа через подтверждённую почту записывается один раз на сессию. Пароли, коды и содержимое сообщений в журнал не попадают.
