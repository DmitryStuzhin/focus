# Архитектура Focus

## Состояние сервера (ТЗ №13)

Версия 0.1.0 рассчитана на один активный процесс приложения. В SQLite сохраняются аккаунты, квоты провайдеров, облачные копии, публикации, результаты фоновых задач и попытки входа. Дневные и месячные бюджеты провайдеров сохраняются при перезапуске.

Минутные лимиты чата и поиска, дневной предел числа поисков Tavily и снимки поисковой выдачи находятся в памяти процесса. После перезапуска эти счётчики обнуляются. Если пропал снимок поиска, приложение просит повторить поиск. Сохранённые денежные лимиты продолжают действовать. Перед запуском нескольких экземпляров перенесите счётчики и снимки в общее хранилище, а запуск фоновых задач — в механизм с единым владельцем задачи.
