# M2. Тест удобства Focus

Статус на 14 ноября 2026 года — 0 из 5 сессий. Наблюдения и список исправлений появятся после тестов.

## Подготовка

Пригласите пять участников из целевых ролей. Откройте одинаковую тестовую версию Focus для каждого, подготовьте отдельный тестовый аккаунт, два небольших CSV и документ с вымышленными условиями. Проверьте доступ к модели для задания с документом. Попросите думать вслух. Названия элементов интерфейса и порядок кликов в заданиях не подсказывайте.

Контрольный набор CSV имеет одинаковые столбцы `id,сумма`. Исходный файл содержит строки `101,1200`, `102,900`, `103,500`. Новый файл содержит `103,500`, `101,1500`, `104,250`. Документ «Условия поставки» содержит фразу «Покупатель оплачивает поставку в течение 10 рабочих дней после подписания акта».

| Задание | Что считается результатом |
| --- | --- |
| Подготовьте место для работы над квартальным отчётом | Появился проект «Квартальный отчёт» |
| Добавьте предоставленный документ в это место | Файл виден в материалах проекта |
| Узнайте, что изменилось между двумя выгрузками | Участник называет изменённую сумму строки 101, удалённую строку 102 и добавленную строку 104 |
| Узнайте срок оплаты и покажите, на чём основан ответ | Участник называет 10 рабочих дней и находит фрагмент про акт |
| Сделайте так, чтобы результат можно было открыть после возвращения в проект | Сохранённый файл появляется в проекте и открывается |

## Запись и приоритизация

Укажите версию приложения, размер экрана, код участника, затраченное время, результат без подсказки, место остановки и дословную короткую реплику без персональных данных. Если участник просит помочь, отметьте задачу как выполненную с подсказкой. В конце уточните, что он ожидал увидеть на месте затруднения.

Сначала исправляйте препятствия, которые остановили задачу или привели к неверному результату, затем повторяющиеся задержки. Выберите пять проблем по наблюдениям и перепроверьте изменённые сценарии на той же тестовой версии, обновлённой соответствующими правками.

Приёмка M2 — пять сессий по пяти задачам, обезличенная таблица наблюдений, пять приоритетных проблем и ссылки на их исправления.
