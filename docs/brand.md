# Бренд Focus

## P1. Рабочая гипотеза позиционирования

**Рабочее место с ИИ, где числа и файлы считаются точно.**

Аудитория для проверки — офисные специалисты, которые регулярно работают с таблицами и документами: бухгалтеры, аналитики и менеджеры малого бизнеса.

| Опора | Как проявляется |
| --- | --- |
| Точность | Встроенные расчёты и сверка используют код. Ответы модели требуют проверки. |
| Приватность | История и файлы по умолчанию хранятся в браузере. Запросы и выбранные вложения передаются подключённому провайдеру, если сценарий требует ИИ. |
| Русский язык | Интерфейс, примеры и подсказки ориентированы на повседневные рабочие задачи на русском. |
| Модели в одном месте | Подключённые провайдеры доступны через общее пространство проекта. Выбор любой модели пользователем зависит от реализации и конфигурации. |

Focus не ведёт бухгалтерский или юридический учёт, не подписывает документы, не исполняет серверные команды из ответов модели и не гарантирует достоверность сгенерированных выводов.

Статус гипотезы — не проверена, 0 интервью. Проверьте по [M1](research/interviews.md). Согласование владельцем и применение позиционирования к интерфейсу и README следуют после результатов.

## P3. Слоган и описания

Варианты для согласования с позиционированием P1. Тексты описывают существующие возможности.

- Слоган — «Сверяйте таблицы. Разбирайте документы с ИИ.» (6 слов).
- Описание для поиска и соцсетей — «Сверяйте таблицы, проверяйте расчёты и разбирайте документы с ИИ. Проекты, диалоги и файлы в одном рабочем пространстве.» (120 символов).
- GitHub — «Рабочее пространство с ИИ для сверки таблиц, точных расчётов и работы с документами».
- App Store и Google Play — «Сверяйте выгрузки, проверяйте расчёты и задавайте вопросы по документам. Объединяйте диалоги и файлы в проекты, чтобы возвращаться к результатам. Для запросов к модели требуется подключение к интернету и вход в аккаунт. История и файлы по умолчанию остаются на вашем устройстве».

Текст для магазинов подготовлен для будущего приложения. Перед публикацией проверьте каждое обещание на фактической мобильной версии.

## P4. Голос и словарь

Обращайтесь на «вы». Действия на кнопках называйте инфинитивами («Создать проект»), а инструкции формулируйте вежливо («Выберите файл»). Используйте точку вместо восклицательного знака. Избегайте слов «магия» и «революция». В ошибке сообщайте, что произошло и что можно сделать. При описании лимита называйте окно и единицу. Отдельно описывайте действия модели, расчёты программы и передачу данных.

| Термин | Значение |
| --- | --- |
| Проект | Группа связанных диалогов и файлов |
| Диалог | Последовательность сообщений по одной задаче |
| Файл | Загруженный или сохранённый результат |
| Инструмент | Действие с конкретным результатом, например расчёт |
| Модель | Система, которая генерирует ответ |
| Провайдер | Сервис, через который выполняется внешний запрос |
| Лимит | Объём использования в определённом окне |

Режимы ответа — «Быстро», «Обычно», «Подробно». Смена названий режимов относится к U11. Идентификаторы команд сохраняются: `/calc` — «Рассчитать», `/stats` — «Посчитать статистику», `/convert` — «Перевести единицы», `/csv` — «Проанализировать CSV», `/csvdiff` — «Сверить таблицы», `/diff` — «Сравнить текст», `/json` — «Проверить JSON».
