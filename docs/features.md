# Возможности Focus

## Подтверждение генерации (ТЗ №17)

Focus показывает распознанное действие перед генерацией изображения, сайта, игры или приложения. Кнопка «Запустить» отправляет запрос, «Отмена» закрывает подтверждение. Сохранение сгенерированных файлов и открытие HTML-предпросмотра выполняются отдельными действиями.

## Тема (ТЗ №18)

Новое пространство следует системной теме. Можно выбрать светлую, тёмную или системную тему в настройках. Сохранённый выбор применяется при следующем открытии.

## Доступность (ТЗ №19)

Интерактивные элементы получают видимый фокус. Диалоги возвращают фокус к открывшему их элементу, пока он существует на странице. Поток ответа объявляется через `aria-live`. Общая палитра усиливает контраст второстепенного текста и учитывает настройку уменьшения движения.

## Название (ТЗ №20)

Интерфейс и ответы используют имя Focus. Старые папки Forge распознаются при открытии проектов и переименовываются при сохранении новой версии.

## Атрибуция (ТЗ №21)

Страница «О проекте» доступна из настроек и подвала экрана входа. На ней указаны Unslop, автор, лицензия CC BY 4.0 и факт адаптации рекомендаций.

## Проверки встроенных операций (ТЗ №22)

Тесты проверяют вычисления, статистику, CSV, сравнение текста и таблиц, JSON, формат Office и восстановление резервной копии. Браузерный сценарий проверяет миграцию локального хранилища и загрузку 500 диалогов и 200 файлов.

## Встроенные команды

- Введите `/calc (125 + 18) * 1,2`, чтобы получить точный результат. Поддерживаются скобки, +, −, *, /, целые степени через ^ и проценты через % (например, 15% * 800).
- Введите `/stats 12; 18; 21; 24`, чтобы получить количество, сумму, среднее, медиану, минимум и максимум. Числа можно разделять пробелами, точками с запятой или переносами строк. Десятичные дроби можно вводить с запятой или точкой.

Команды работают прямо в чате без ключа модели. Переключатель темы находится в верхней панели. По умолчанию тема следует настройкам устройства.


## Генерация изображений

Откройте раздел «Изображения», выберите модель и формат и опишите изображение. Изображение после подтверждённой генерации сохраняется в галерее и файлах проекта. В диалоге базовую генерацию можно запустить командой `/image кот-космонавт на Луне`.

Для генерации в рамках бесплатной квоты выберите тариф Workers Free. В [панели Cloudflare](https://dash.cloudflare.com/) откройте Workers AI → Use REST API и получите Account ID и Workers AI API Token.

Добавьте на VPS в приватное окружение сервиса следующие переменные.

```dotenv
CLOUDFLARE_ACCOUNT_ID=идентификатор_аккаунта
CLOUDFLARE_API_TOKEN=токен_workers_ai
```

Перезапустите приложение командой `sudo systemctl restart focus`. Генерация через Cloudflare теперь предпочитает FLUX.2 Klein 9B; при временной перегрузке доступен резерв Klein 4B. 9B расходует больше квоты, поэтому прежняя оценка количества бесплатных изображений для 4B больше не применима. Лимиты зависят от тарифа и общей квоты аккаунта. Для широкого или вертикального кадра добавьте `--ar 16:9` или `--ar 9:16`.

В режиме по подписке используется OpenAI Image API или настроенная платная модель OpenRouter (`OPENROUTER_API_KEY` и `OPENROUTER_IMAGE_MODEL`).

Команда создаёт изображение по тексту текущего сообщения. Остановка прерывает ожидание, но провайдер может продолжить генерацию и списать стоимость.

### Изображения в обычном диалоге

Напишите «Нарисуй кота» или «Создай изображение города» — команда `/image` необязательна. После результата: «Добавь закат», «Убери фон», «Пусть кот будет черным». Каждый запрос правки отправляет последнюю успешную картинку из этого диалога выбранной модели. Предыдущие версии остаются в истории. Явная новая просьба «Нарисуй…» начинает новое изображение.

В диалоге редактирование работает через Cloudflare Workers AI. В разделе «Изображения» можно также править изображения через GPT Image по подписке. Референс уменьшается до 512 px, результат сохраняет исходные размеры или выбранный формат. Квота Cloudflare расходуется и при редактировании.

### GPT Image по подписке

GPT Image 2.5 Sunburst использует отдельный платный проект OpenAI API. В приватном окружении сервиса задайте `FOCUS_OPENAI_IMAGE_API_KEY` и список `FOCUS_IMAGE_SUBSCRIPTIONS`. Один ключ OpenAI без действующего кода не открывает платную генерацию посетителям.

1. После подтверждения оплаты сгенерируйте новый код и его хеш на VPS:
   ```bash
   node -e 'const c=require("node:crypto");const p=c.randomBytes(32).toString("hex");console.log(p);console.log(c.createHash("sha256").update(p).digest("hex"))'
   ```
2. Отправьте подписчику первую строку. Вторую добавьте в `FOCUS_IMAGE_SUBSCRIPTIONS` в формате `хеш:ГГГГ-ММ-ДД`. Дата означает начало суток UTC, когда доступ закончится. Несколько записей разделяются запятой. Чтобы отозвать код, удалите запись.
3. Выполните `sudo systemctl restart focus`. Подписчик выбирает режим по подписке в разделе «Изображения» и вводит код на странице HTTPS. При включённом входе по email код привязывается к аккаунту. Базовый режим доступен отдельно.

Выдача, продление и отзыв кодов выполняются администратором. Приём платежей и автоматическая выдача кодов пока не подключены.

### Дополнительные навыки

- `/convert 2,5 км в м` точно переводит единицы длины, массы, времени и объёма без запроса к модели.
- «Найди в интернете …» и «Проверь в сети …» запускают подключённый серверный поиск без ручного переключателя.
- `/csv` анализирует один прикреплённый CSV: строки, пропуски, минимум, максимум, сумму и среднее числовых столбцов. Первая строка — заголовки. До 5000 строк и 64 столбцов. Если нужно указать разделитель, используйте `/csv ;`, `/csv ,` или `/csv табуляция`.
- `/diff` сравнивает два прикреплённых текстовых файла построчно. Прикрепите старую версию первой, новую второй. До 500 строк на файл.

Оба навыка считают данные на сервере Focus без запроса к модели.

### Постеры и обложки

В бесплатном режиме запрос «Сделай постер для джазового концерта --ar 9:16» выбирает Leonardo Lucid Origin через Cloudflare. У модели отдельный сценарий для создания графики с нуля. Следующие правки изображения выполняются через модель редактирования. Режим расходует общую квоту Cloudflare вместе с FLUX.

### Режим программирования

Нажмите «Написать код» или отправьте, например, «Напиши код HTTP-сервера на Go с тестами». Focus читает приложенные исходники и доступный текст файлов проекта, предлагает код, объясняет правку и может дать команды для проверки. Поддерживаются, среди прочего, Python, JavaScript, TypeScript, Go, Rust, C/C++, Java, C#, SQL и Bash.

Блоки кода можно копировать и скачивать отдельно. В режиме Focus Code (`/code`) именованный блок можно открыть через «Сохранить в проект». Для замены прикрепите существующий файл к запросу. В окне просмотра можно сравнить текущий и предложенный текст. Focus Code сверяет содержимое с версией из запроса, чтобы не перезаписать изменённый или частично прочитанный файл. Новые файлы сохраняются в корне текущего проекта.

Код сохраняется в рабочем пространстве браузера. Для запуска команд и тестов используйте свою среду разработки.

«Продумать план» или «Составь план обновления приложения» создаёт чек-лист. Отмеченные пункты сохраняются в диалоге и учитываются в последующих сообщениях. «Проверить код» или «Проверь код: найди ошибки в обработке пустого ввода» помогает провести ревью. Прикрепите исходники или файл с изменениями. Для коротких цельных файлов Focus передаёт модели номера строк, чтобы находки было легче проверить.

При просмотре предложенной замены файла в режиме `/code` показываются добавленные и удалённые строки. Для версий длиннее 500 строк доступны оба исходных текста.

### Предпросмотр сайта

Нажмите «Создать сайт» или напишите «Сделай сайт для портфолио». После подтверждения Focus подготовит HTML со встроенными CSS и JavaScript и откроет результат справа от чата на широком экране. «Предпросмотр» под блоком HTML открывает выбранную версию, в том числе на узком экране. Попросите изменить страницу в чате, чтобы обновить предпросмотр.

Предпросмотр запускается в отдельной рамке с изолированным происхождением. Встроенный JavaScript работает, внешние ресурсы и запросы из скриптов блокируются. Для проекта с серверным кодом, пакетами или внешними API скачайте исходник и запустите в своей среде.

Если внешний сервис вернул ошибку, пустой или оборванный ответ при создании сайта, Focus подготавливает локальную стартовую страницу. Для стоматологии предусмотрена отдельная заготовка с услугами и FAQ. Заполните контакты и проверьте тексты перед публикацией. При сбое редактирования предыдущая версия остаётся в предпросмотре.

«Найди в проекте loginUser» ищет строку по текстовым файлам текущего проекта в браузере. Нажмите на результат, чтобы открыть совпадение с соседними строками. Этот поиск работает без ключа модели. При обычном запросе Focus также подбирает контекст по содержимому файлов и их именам.

### Просьбы в обычном сообщении

Напишите «У меня небольшая клиника. Сделай сайт для неё» или «Вот набросок, а теперь нарисуй по нему постер». Focus ищет подходящее действие внутри сообщения. Примеры в кавычках и блоки кода не запускают инструменты сами по себе.

«Проверь JSON» или «Отформатируй JSON» проверяет вставленный текст или один прикреплённый JSON-файл. Focus выдаёт готовый `data.json` или указывает на синтаксическую ошибку. Этот инструмент работает без вызова модели.

### Игры и приложения

«Сделай мне залипательную игру на мобилку» готовит браузерную игру для изолированного предпросмотра. «Собери приложение для учёта расходов» открывает интерактивное приложение. Опишите нужные функции или попросите Focus придумать механику. Правки можно попросить в чате, например «Сделай игру сложнее». HTML можно скачать.

Предпросмотр изолирован от сети и хранилища браузера. Для приложения с аккаунтами или сервером он показывает клиентскую часть. Если модель недоступна при создании игры, Focus предложит запасную мини-игру. Для явно запрошенного проекта на Unity, Flutter, SwiftUI или под APK используется режим исходного кода с инструкциями по сборке.

### Сверка файлов

Прикрепите старую и новую выгрузки в этом порядке и напишите «Сравни, пожалуйста, CSV по столбцу id». Focus сопоставит записи по точному значению ключа, даже если строки и столбцы переставлены. Он покажет новые, удалённые и изменённые записи, номера записей в обоих файлах и старые и новые значения. Заголовки должны быть уникальными, а ключ должен быть заполнен и встречаться один раз в каждом файле. По умолчанию ключ называется `id`. Сравнение не требует вызова модели.

«Проверь по документу, когда нужно оплатить счёт» включает режим ответа с подтверждениями из доступных файлов. Для полного короткого текстового вложения Focus получает номера строк. Если доступен только фрагмент, в контексте он помечается как фрагмент.
