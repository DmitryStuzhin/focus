# Развёртывание Focus

Focus работает на Node.js 22 на Debian или Ubuntu. TLS завершает nginx или другой настроенный прокси. Для установки используйте скрипты выбранного релиза. Настройки конкретной установки храните в приватном runbook.

## Подготовка

1. Настройте DNS и сертификат для домена приложения.
2. Подготовьте закрытое окружение процесса, включите вход и задайте бюджет активных провайдеров. Список переменных и правила доверия к nginx описаны в [инструкции по эксплуатации](../docs/operations.md).
3. Установите сервис и проверьте готовность на `/healthz`. Войдите по почте и проверьте чат и подключённые провайдеры из аккаунта.

## Автодеплой

Сервис обновления проверяет успешный GitHub Actions для точного коммита ветки `main`. Сборку и тесты запускает отдельный пользователь. Сервис переключает релиз, перезапускает приложение и возвращает предыдущий релиз при сбое проверки готовности. Перезапуск создаёт короткую паузу. Актуальные команды и рабочие адреса храните в приватном runbook.

## Почта и доступ

Для входа поддерживаются SMTP и Yandex Cloud Postbox. При использовании Postbox подтвердите домен через DKIM, выдайте сервисному аккаунту роль `postbox.sender` и храните его статический ключ в закрытом окружении сервиса. Для проверки запросите код в интерфейсе и завершите вход.

Для отдельного входа администратора используйте `deploy/connect-admin.sh` из проверенного релиза. Перед включением панели настройте `FOCUS_ADMIN_ALLOWED_IPS`. [Эксплуатация и администрирование](../docs/operations.md)
